**Categoría:** Belleza / Estética  
**Tipo de negocio:** Peluquería, Spa, Manicura & Estética  
**Perfil becario:** B (personas)

---

## Descripción

Plantilla web premium para negocios del sector belleza y estética (peluquerías, salones de spa, centros de manicura y estética facial). Diseño elegante con tonos crema, rosados y dorados que transmiten lujo accesible y bienestar.

### Páginas incluidas

| Ruta | Página | Contenido |
|---|---|---|
| `/` | **Inicio** | Hero con imagen, estadísticas, 3 servicios destacados, testimonios, banner CTA |
| `/nosotras` | **Nosotras** | Historia del salón, valores, equipo de 4 especialistas |
| `/servicios` | **Servicios** | 16 servicios con filtro por categoría, precios y duración |
| `/contacto` | **Contacto** | Formulario validado, horarios, mapa y datos de contacto |

---

## Stack tecnológico

- **React 19** + **TypeScript**
- **Vite 8** con **Tailwind CSS v4** (`@tailwindcss/vite`)
- **React Router v7**
- **lucide-react** para iconografía

---

## Cómo ejecutar

```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm dev

# Build de producción
pnpm build

# Preview del build
pnpm preview
```
