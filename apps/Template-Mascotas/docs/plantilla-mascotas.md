# Plantilla PetCare Mascotas

## Objetivo
Crear una mini-web de ejemplo para un negocio de mascotas que funcione como punto de partida para clientes reales de XYZ Digital.

## Alcance
Esta plantilla incluye:
- Portada con llamada a la acción
- Sección "Sobre nosotros"
- Servicios destacados
- Contacto con formulario y datos de la empresa

## Categoría
Pet care / Veterinaria
- Clínica veterinaria
- Peluquería canina
- Tienda de productos para mascotas

## Tecnologías usadas
- React 19
- TypeScript
- Vite
- CSS moderno responsive

## Calidad y accesibilidad
La plantilla está diseñada para cumplir los requisitos de calidad:
- Estructura semántica con header, main, section y footer
- Navegación por teclado
- Texto legible y contraste adecuado
- Formularios etiquetados
- Título y meta descripción en `index.html`

## Cómo usar
1. Ejecutar `pnpm install`.
2. Iniciar con `pnpm dev`.
3. Abrir `http://localhost:5173`.

## Notas
La plantilla es un ejemplo funcional y está lista para copiar o adaptar a nuevas categorías dentro de la sección "Mascotas".
