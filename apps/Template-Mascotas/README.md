# Plantilla PetCare Mascotas

Proyecto de ejemplo para una mini-web de mascotas creada como plantilla de negocio.

## Contenido
- `src/App.tsx`: landing page para negocio de mascotas con portada, servicios, sobre nosotros y contacto.
- `src/App.css`: estilos responsivos y accesibles para la plantilla.
- `index.html`: incluye `title` y `meta description` para SEO.
- `docs/plantilla-mascotas.md`: documentación de la plantilla y guía de uso.

## Descripción
Esta plantilla está pensada para:
- Clínicas veterinarias
- Peluquerías caninas
- Tiendas de productos para mascotas
- Negocios de cuidado y alojamiento de mascotas

## Cómo ejecutar
1. Instalar dependencias:
   ```bash
   pnpm install
   ```
2. Iniciar desarrollo:
   ```bash
   pnpm dev
   ```
3. Abrir `http://localhost:5173`

## Requisitos mínimos
- Node.js 22 LTS
- pnpm
- Visual Studio Code
- Git

## Calidad
La plantilla se ha construido con atención a:
- Experiencia responsive para móvil, tablet y escritorio
- Accesibilidad en formularios y navegación
- SEO básico con título y descripción
- Código React + TypeScript limpio y reutilizable
