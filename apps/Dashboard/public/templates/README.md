# Imágenes de las Plantillas (xyz-templates)

Para mostrar una imagen personalizada en las tarjetas del Dashboard y en su página de detalle, coloca las imágenes en esta carpeta (`apps/Dashboard/public/templates/`).

## Formato y Nombre del Archivo

El sistema está configurado para buscar automáticamente las imágenes en base al **slug** (identificador) de cada plantilla.

### Nombre del archivo:
El nombre del archivo debe coincidir **exactamente** con el slug de la plantilla en minúsculas. El sistema probará primero con formato `.jpg` y, si no lo encuentra, intentará con `.png`.

### Listado de nombres recomendados:

1. **Inmobiliaria Residencial**:
   * Nombre: `inmobiliaria-residencial.jpg` (o `inmobiliaria-residencial.png`)
2. **Gimnasio**:
   * Nombre: `template-gimnasio.jpg` (o `template-gimnasio.png`)
3. **Turismo**:
   * Nombre: `turismo-template.jpg` (o `turismo-template.png`)
4. **Agencia de Viajes**:
   * Nombre: `agencia-viajes.jpg` (o `agencia-viajes.png`)
5. **Belleza**:
   * Nombre: `template-belleza.jpg` (o `template-belleza.png`)
6. **Transporte**:
   * Nombre: `transporte-template.jpg` (o `transporte-template.png`)
7. **Clínica Dental** (Próximamente):
   * Nombre: `clinica-dental.jpg`
8. **Energía Renovable** (Próximamente):
   * Nombre: `energia-renovables.jpg`
9. **Hotel** (Próximamente):
   * Nombre: `hotel.jpg`
10. **Inmobiliaria Comercial** (Próximamente):
    * Nombre: `inmobiliaria-comercial.jpg`
11. **Logística y Transporte** (Próximamente):
    * Nombre: `logistica-transporte.jpg`
12. **Restaurante** (Próximamente):
    * Nombre: `restaurante.jpg`
13. **Tienda Online** (Próximamente):
    * Nombre: `tienda-online.jpg`

---

*Nota: Si no agregas ninguna imagen para una plantilla, el sistema automáticamente mostrará un fondo degradado con la letra inicial de la plantilla de manera elegante y fluida.*
